# PORTFOLIO RULES

## Objective

The portfolio must present me as a professional Information Security graduate applying for Junior Information Security Engineer, Security Engineer, PKI Engineer, SOC Analyst and Security Software Engineer positions.

The portfolio must prioritize credibility over visual effects.

---

## Design Principles

Minimalistic.

Professional.

Fast loading.

Responsive.

Dark theme.

No unnecessary animation.

No hacker-style gimmicks.

---

## Content Principles

Every project must answer:

Problem

Architecture

My contribution

Key features

Security considerations

Limitations

Future improvements

Repository

Documentation

Demo

---

## Writing Style

Professional.

Objective.

No marketing language.

Never exaggerate experience.

No fake achievements.

Only describe work that can be demonstrated.

---

## Code Rules

Clean architecture.

Reusable components.

Semantic HTML.

Responsive layout.

No inline CSS.

No duplicated code.

Follow ESLint.

---

## Security Rules

Never expose:

passwords

private keys

API keys

connection strings

tokens

email credentials

---

## Portfolio Goal

Recruiters should understand the entire portfolio within 3 minutes.

Senior engineers should be able to evaluate technical depth within 10 minutes.
